# 候補の質問（2026-09-24）

この下の ScoreFile は、使い捨てのスクリプトで Jev に聞いた候補の質問の結果（`npm run validate:agreement -- reports/validation/2026-09-24/candidates` で [summary.md](summary.md) を再生成できる）。
スクリプトはコミットしていない。質問文はここに残す。採用したものは `skills/*/scripts/evaluate.ts` に入っている。
モデルは `jev-latest`（jev-1.13.0）。状態は `{お題, 回答}`、一対比較は `{お題}` と選択肢 `回答: …` で、提示順を入れ替えた2回の平均。

## 回答単位（noul / choice / score）

| キー | 質問 | 結果 |
|---|---|---|
| `concrete` | 回答に、質感のある具体的な物、実際に起きている現象、または制度・設備・役割の具体的な異常が出てくるか？ | **採用**（fun-check `noPictureRisk` を反転） |
| `concrete2` | 回答の中に、目に見える具体的な物か、実際に起きている出来事があるか？ | `concrete` とほぼ同じ |
| `conceptOnly` / `conceptRisk` | 物も現象も出てこず、ルールや概念の言い換え・論理の反転だけで成立しているか？ | `concrete` の否定形。やや弱い |
| `explanatory` | 同じ着眼点を、説明的・遠回しに言っているか？ | **採用**（fun-check `lengthRisk`） |
| `lengthRisk2` | 同じ着眼点のまま、もっと直球で短く言い切れるか？ | `explanatory` と同程度、一対比較が弱い |
| `exaggerationOnly` | 程度を盛る（すごい・多い・長い）ことだけで成立しているか？ | 弱い |
| `cleverOnly` | うまいことを言っているだけで、声を出して笑うところがないか？ | 逆向き |
| `bold` | 一読で一枚の絵が浮かぶ、大胆でわかりやすい回答か？ | 判別力なし |
| `laugh` | 会場で読み上げたときの客席の反応（反応なし／ニヤリ・感心／声を出して笑う） | 「声を出して笑う」の確率は逆向き |
| `formFit` | お題が求めている形式にそのまま答えているか？ | 逆向き。この検証データには形式外れの回答がほぼない |
| `heOverallRich` | humor-eval の Overall に、足切りの前提とアンカーを書き足した score | 逆向き（0.39）。説明を足しても直らない |
| `typical` | fun-check の相対典型性（セット全体の choice） | 判別力なし |

## 一対比較（choice、どちらか）

| キー | 質問 | 結果 |
|---|---|---|
| `adopt` | この2つの回答のうち、採用に近づけるべきなのはどちらか？（旧 humor-rank） | チャンスレベル |
| `funny` | 大喜利の回答として、どちらが面白いか？ | 逆向き。確信度の高い判定ほど外れる |
| `laugh` | 客席がより大きく笑うのはどちらか？ | 同上 |
| `recover` | お題とのズレを1文で自然に回収できるのはどちらか？ | 逆向き（0.36） |
| `picture` | 一読で場面（一コマの絵）が浮かぶのはどちらか？ | 判別力なし |
| `concrete` | 質感のある具体的な物、または実際に起きている現象・出来事がはっきり置かれているのはどちらか？ | **採用**（humor-rank） |
| `straight` | 説明や前置きがなく、直球で短く言い切っているのはどちらか？ | **採用**（humor-rank） |
| `novel` | 発想が新しいのはどちらか？ | 判別力なし |
