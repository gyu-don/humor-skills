# 被りチェック

## 準備

- Node.js 22.6以上、環境変数 `TYPESAFE_API_KEY`
- 初回のみ、このディレクトリで `npm install`

## 使い方

```
node scripts/evaluate.ts <入力.json> [出力.json]
```

- 入力: `{"topic": "...", "answers": ["...", ...]}`、または複数セットの配列（見本は `assets/samples.json`）
- 出力:
  - `summaries[].nearDuplicates`: 被りと判定したペア（回答番号の組）
  - `overlaps[].sameMaterial`: 全ペアについて、同じ素材を使っている確率（0.7以上を被りとする）

被りとみなすのは、笑いの中心の素材（物・人・場所・出来事）が同じペア。お題の前提、書き出しの言葉、お題が決める形式が共通しているだけなら被りではない。

## 合否の決め方

`nearDuplicates` が1件以上あれば不合格。

お題が回答の形式を決める場合（全回答がカタカナ語、など）は、確率が閾値のすぐ下に集まる。そのときは、変更前の版と `sameMaterial` を並べて比べる。

## 検出できないもの

素材は違うが同じ方向にひねった回答が並ぶ、セット全体の収束。これは人間が確認する。

## 信頼度

人間のブラインド判定16組（2026-09-23）での結果は次のとおり。2回の実行間の相関は r≈0.99。

- 被り5組のうち3〜4組を検出した
- 被りでない10組の誤検出は0
